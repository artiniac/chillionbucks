# Artin and Leo: photo-derived 3D avatars

Owner-provided family photographs were used to produce identity reference portraits through Higgsfield GPT Image 2.5, then textured 3D models through Tripo H3.1 Image to 3D in Higgsfield. Detailed geometry and textures, target 100,000 faces per model, source-image texture alignment, and PBR enabled.

- Artin reference job: 984afb32-1bb6-4451-8f48-c5d0319443bc
- Artin model job: 253054d5-04a8-4a3f-af65-3d071ad952a2
- Leo reference job: 847e9cae-3a5d-4d0b-a382-0d608929d4bc
- Leo model job: 21940898-4765-4adc-91dd-8e83a70cb5d8

The models have real head, face, hair, ear, and neck geometry with embedded textures. These are AI reconstructions, not measured scans. Side and rear details are inferred. Head movement is animated in game; facial expressions are baked into the generated models. The original family photographs and rejected prototypes are not distributed.
